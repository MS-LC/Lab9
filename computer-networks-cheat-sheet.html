Ethernet & LAN

  • CSMA/CD: sense → send → collision → abort → backoff in [0, 2min(n,10)−1] slots.
  • 64 B minimum so the sender is still transmitting when a worst-case collision returns.
  • Switch: learn src→port, forward known unicast, flood unknown/broadcast, age out. Splits collision domains, not broadcast.
  • VLAN 12-bit tag; trunks carry tagged frames. STP: root = lowest ID, block redundant links.
  • Wi-Fi: CSMA/CA (cannot detect collisions while sending) + ACK after SIFS; RTS/CTS for hidden terminals.

IP & companions

Header: Ver · IHL · DSCP/ECN · Len · ID · Flags · FragOff · TTL · Proto · Cksum · Src · Dst. TTL drops per hop; checksum covers the header only.

Addresses: private 10/8, 172.16/12, 192.168/16 · loopback 127/8 · link-local 169.254/16 · multicast 224/4. Forward by longest-prefix match.

Fragmentation — 4000 B over MTU 1500 (offsets in 8-byte units)

Frag: MF=0 on last, reassemble only at destination; DF → ICMP → PMTUD. NAT rewrites IP:port. ARP IP→MAC in LAN. DHCP = DORA. ICMP errors, no ports. DNS UDP/53.

IPv6: 128-bit, 40 B header, no checksum, no router fragmentation; NDP replaces ARP; SLAAC.

Routing

  • DV: Dx(y) = min(c + Dv(y)). Count-to-infinity → split horizon, poisoned reverse, triggered updates, path vector.
  • LS: flood LSAs → topology → Dijkstra. Fast, loop-free. ECMP hashes flows.
  • CIDR: any prefix length, longest match; aggregate contiguous blocks.
  • BGP TCP/179: LOCAL_PREF → AS_PATH → ORIGIN → MED → eBGP > iBGP → IGP cost → router ID.
  • AS_PATH loop detection · valley-free (no free transit) · anycast.

Procedure steps

  • Subnet: mask → AND = network; broadcast = host bits all 1; usable 2h − 2.
  • Fragment: max payload = MTU − 20; offset = cumulative ÷ 8; last MF = 0.
  • CRC: append r zeros → divide by G → append remainder. Dijkstra: min unvisited → relax → repeat.

TCP

Three-way handshake — random ISNs; seq counts bytes, not segments
  • Header: sport · dport · seq · ack · offset · flags · window · checksum · urgent · options. Flags: URG ACK PSH RST SYN FIN.
  • Window = min(cwnd, rwnd); TIME_WAIT = 2 MSL.
  • Nagle: one small unacked segment. Delayed ACK ~200 ms — the two interact badly. Silly window: Clark + Nagle + persist.
  • Karn: no RTT sample on retransmits; double RTO on timeout.

Congestion & QoS

  • AIMD; Reno throughput ∝ 1/RTT.
  • RED: average queue, min_th/max_th/max_p, early drop or mark.
  • ECN marks instead of dropping; big buffers cause bufferbloat.
  • Token bucket (r, β): burst ≤ β; GCRA TAT ← max(now,TAT)+L/r.
  • WFQ finish-time order; Parekh–Gallager delay bound.
  • IntServ per-flow RSVP · DiffServ DSCP/PHB · MPLS labels.

Top traps

  1. Propagation ≠ transmission.
  2. Window = min(cwnd, rwnd).
  3. Fragment offset is in 8-byte units.
  4. Slow start is exponential.
  5. Timeout → cwnd 1; 3 dup → halve.
  6. ssthresh = half of current cwnd.
  7. TCP counts bytes, not segments.
  8. BGP picks policy first.
  9. Count-to-infinity is DV-only.
  10. IPv6: no checksum, no router frag.
  11. RED manages queues, not scheduling.
  12. Token bucket bounds burst, not delay.
